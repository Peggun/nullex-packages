# nullex-packages
The (temporary) storage for packages for the Nullex kernel.

## Publishing
To publish a package, you must create a [GitHub issue](https://github.com/Peggun/nullex-packages/issues/new) with the package details and a link to the package's source code. After this, someone will clone your code, review it for malware, compile it, and add it to the package repository. It must support x86_64 ELF.
