# nullex-packages
The (temporary) storage for packages for the Nullex kernel.

## Publishing
To publish a file, the file needs to be in the ELF x86_64 format and ends in `.elf`. You can successfully compile Nullex-supported code by installed the nullex-libc headers and also
using the `programs/` folder `Makefile` in the [nullex kernel repository](https://github.com/Peggun/nullex).
