the package storage for nullex

search, install and update packages straight from the nullex terminal.


  






  

    
    
  

  






  
usage

  

    
nget <url>download any url

    
nget search [term]search the repository

    
nget info <pkg>show package information

    
nget install <pkg>install a package

    
nget listlist installed packages

    
nget remove <pkg>remove a package

    
nget updateupdate installed packages

  






  
publish a package

  
    
    
  1. create a new github issue with the package details, and the link to the packages source code
    2. 
    
  2. someone will review, and compile your program, whilst also ensuring it works as expected, and is malware free
    3. 
    
  3. once approved, they will commit & push — the site and nget pick it up automatically, and will make it available for installation publicly
